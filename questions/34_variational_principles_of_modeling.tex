\section{Вариационные принципы построения математических моделей}
\label{sec:variational-principles-of-modeling}

\textbf{Вариационный принцип} --- способ построения математической модели,
при котором истинное состояние системы определяется из условия
стационарности некоторого функционала.

Общее условие:
\[
\boxed{\delta J=0},
\]
где $J$ --- функционал, зависящий от искомой функции или траектории.

\textbf{Функционал} --- величина, которая каждой функции ставит в
соответствие число. Например,
\[
J[u]=\int_a^b F(x,u,u')\,dx.
\]

Вариационный подход позволяет перейти от интегрального принципа
к дифференциальным уравнениям.

Основная схема:
\[
\boxed{
	\text{функционал}
	\rightarrow
	\delta J=0
	\rightarrow
	\text{уравнение Эйлера--Лагранжа}
}
\]

\subsection{Функционал действия и энергетические функционалы}

В механике основным функционалом является \textbf{действие}:
\[
\boxed{
	S[q]=\int_{t_1}^{t_2}L(q,\dot q,t)\,dt
}
\]
где $L$ --- лагранжиан:
\[
\boxed{L=T-V}.
\]

Здесь $T$ --- кинетическая энергия, $V$ --- потенциальная энергия.

Для задач статики часто используется \textbf{полный потенциальный
	функционал}:
\[
\boxed{\Pi=U-W},
\]
где $U$ --- внутренняя энергия, $W$ --- работа внешних сил.

Условие равновесия:
\[
\boxed{\delta\Pi=0}.
\]

Если равновесие устойчиво, часто имеет место минимум:
\[
\Pi\rightarrow\min.
\]

Важно: в общем случае вариационный принцип требует именно
\textbf{стационарности}, а не обязательно минимума.

\subsection{Принцип стационарного действия}

\textbf{Принцип стационарного действия}:

\begin{quote}
	Реальное движение механической системы происходит по такой траектории,
	для которой действие стационарно.
\end{quote}

Математически:
\[
\boxed{\delta S=0}.
\]

При этом начальное и конечное положения фиксированы:
\[
\delta q(t_1)=\delta q(t_2)=0.
\]

Рассматривается небольшое изменение траектории:
\[
q(t)\rightarrow q(t)+\varepsilon\eta(t),
\]
где $\eta(t)$ --- произвольная допустимая вариация.

Из условия
\[
\delta S=0
\]
получаются уравнения движения --- уравнения Эйлера--Лагранжа.

Таким образом, принцип стационарного действия является вариационной
формулировкой законов механики.

\subsection{Принцип возможных перемещений}

Для равновесия механической системы используется
\textbf{принцип возможных (виртуальных) перемещений}.

Он утверждает:

\begin{quote}
	Для равновесной системы сумма виртуальных работ всех действующих сил
	на любом допустимом виртуальном перемещении равна нулю.
\end{quote}

Математически:
\[
\boxed{\delta W=0}.
\]

Для системы материальных точек:
\[
\sum_i \mathbf F_i\cdot\delta\mathbf r_i=0.
\]

Если силы консервативны, то
\[
\delta W=-\delta V,
\]
поэтому
\[
\delta V=0.
\]

Для упругой системы удобно записывать:
\[
\boxed{\delta\Pi=0},
\qquad
\Pi=U-W.
\]

Таким образом, принцип возможных перемещений и энергетический
вариационный принцип выражают одну основную идею:

\[
\boxed{
	\text{равновесное состояние}
	\;\Longleftrightarrow\;
	\text{стационарность соответствующего функционала}.
}
\]

\subsection{Уравнения Эйлера--Лагранжа}

Пусть задан функционал
\[
J[u]=\int_a^b F(x,u,u')\,dx.
\]

Требуется найти функцию $u(x)$, для которой
\[
\delta J=0.
\]

Из этого условия получается \textbf{уравнение Эйлера--Лагранжа}:
\[
\boxed{
	\frac{\partial F}{\partial u}
	-
	\frac{d}{dx}
	\left(
	\frac{\partial F}{\partial u'}
	\right)=0
}.
\]

Для механической системы с лагранжианом $L(q,\dot q,t)$:
\[
\boxed{
	\frac{d}{dt}
	\frac{\partial L}{\partial\dot q}
	-
	\frac{\partial L}{\partial q}=0
}.
\]

Для нескольких обобщённых координат:
\[
\boxed{
	\frac{d}{dt}
	\frac{\partial L}{\partial\dot q_i}
	-
	\frac{\partial L}{\partial q_i}=0,
	\qquad i=1,\ldots,n.
}
\]

Это основная формула, связывающая вариационный принцип
с дифференциальными уравнениями движения.

\subsection{Учёт связей и ограничений}

В реальных механических системах координаты могут быть связаны
условиями:
\[
f(q_1,\ldots,q_n,t)=0.
\]

Для учёта таких связей используется
\textbf{метод множителей Лагранжа}.

Вместо исходного функционала рассматривают расширенный:
\[
\boxed{
	\widetilde J=J+\lambda f
}.
\]

Условие стационарности:
\[
\delta\widetilde J=0.
\]

Для нескольких связей:
\[
\widetilde J
=
J+\sum_\alpha\lambda_\alpha f_\alpha.
\]

Множители Лагранжа позволяют учитывать ограничения системы
и могут иметь смысл реакций соответствующих связей.

\subsection{Диссипативные системы}

Классический принцип стационарного действия естественным образом
применяется к \textbf{консервативным системам}.

В реальных системах имеются потери энергии:
трение, вязкое сопротивление и т.\,п.

Для учёта вязкой диссипации вводится
\textbf{функция Рэлея}:
\[
\boxed{
	\mathcal R=
	\frac12\sum_{i,j}c_{ij}\dot q_i\dot q_j
}.
\]

Уравнения движения принимают вид:
\[
\boxed{
	\frac{d}{dt}
	\frac{\partial L}{\partial\dot q_i}
	-
	\frac{\partial L}{\partial q_i}
	+
	\frac{\partial\mathcal R}{\partial\dot q_i}
	=
	Q_i
}.
\]

Простейший пример:
\[
\boxed{
	m\ddot x+c\dot x+kx=F(t).
}
\]

Здесь $c\dot x$ --- сила сопротивления.

Главная идея:
\[
\boxed{
	\text{к уравнениям Эйлера--Лагранжа добавляется
		член, описывающий диссипацию}.
}
\]

\subsection{Примеры вариационных моделей}

\textbf{Груз на пружине}

Кинетическая энергия:
\[
T=\frac{m\dot x^2}{2},
\]

потенциальная энергия:
\[
V=\frac{kx^2}{2}.
\]

Лагранжиан:
\[
L=\frac{m\dot x^2}{2}-\frac{kx^2}{2}.
\]

По уравнению Эйлера--Лагранжа:
\[
\frac{d}{dt}\frac{\partial L}{\partial\dot x}
-
\frac{\partial L}{\partial x}=0.
\]

Получаем:
\[
\boxed{
	m\ddot x+kx=0
}.
\]

Таким образом, уравнение гармонических колебаний получается
из принципа стационарного действия.

\textbf{Упругая балка}

Пусть $u(x)$ --- поперечное перемещение балки.

Энергия изгиба:
\[
U=
\frac12\int_0^L EI(u'')^2\,dx.
\]

Работа внешней нагрузки:
\[
W=\int_0^Lq(x)u(x)\,dx.
\]

Функционал полной потенциальной энергии:
\[
\Pi=U-W.
\]

Условие равновесия:
\[
\boxed{\delta\Pi=0}.
\]

Из него получается уравнение балки:
\[
\boxed{
	EIu''''=q(x)
}
\]
с соответствующими граничными условиями.

Этот пример показывает применение вариационного подхода
к механике деформируемого тела.
